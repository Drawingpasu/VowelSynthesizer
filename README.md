## generator.py t dfdf

.generate_sin(sample_rate, duration, freq, bit_depth, dB)
- sample_rate: 샘플레이트... 기본값은 48000
- duration: 지속시간(실수, 단위는 초)... 기본값은 10.0
- freq: 주파수(Hz)... 기본값은 1000
- bit_depth: ㄹㅇ 말 그대로, 별로 중요한 요소 아님... 기본값은 0
- dB: 넘파이 배열로 받음. 기본적으로 -12dB 되어있음. 나중에 다 소리 가산해서 합쳤을때 깨지는거 방지

- numpy.ndarray형을 반환함

.write_wav(filename, stereo_data, sample_rate, bit_depth)
- filename: 스트링으로 받음. 파일 이름임. 뒤에 자동으로 .wav가 붙어서 저장됨
- stereo_data: numpy.ndarray형이 들어감. 위의 .generate_sin()로 만든애가 들어갈 수 있음
- sample_rate: 샘플레이트... 기본값은 48000
- bit_depth: ㄹㅇ 말 그대로, 별로 중요한 요소 아님... 기본값은 16

## gen_vowel.py
아마 이제 최종 프로그램에서는 이친구를 많이 쓸거심

.make_sound(vowel, f0, duration, sample_rate)

- vowel: 어떤 모음을 생성할지 넣으면 됨. 예를들어서 아면 '아' 또는 'ㅏ'를 넣으면 됨.
- f0: 기음이 몇 Hz일지 쓰면 됨. 근데 얘 튜플임!!! 예를들어 (260, 520)이면 지속시간동안 260Hz에서 520Hz로 선형으로 변화함
- duration: 지속시간(실수, 단위는 초)
- sample_rate: 샘플레이트... 기본값은 48000

- numpy.ndarray형을 반환함

로직 간단하게 설명하자면 다음과같음
1. 일단 넘파이 안 인자로 들어가야하는 놈들이기 때문에 f0 안 애들을 정수화를 시켜준다
2. 배음 몇개 깔지 계산한다. 낮은 것 기준으로 계산해야 안전하기 때문에 최솟값을 가려내준다
3. 배음을 만들자. 계속 가산(+ 연산)해야 하기 때문에 그 더할 밑그릇을 output으로써 만들어준다. 그냥 주파수 0으로 해두면 끝
   1. curfreq과 nextfreq로 지금 당장 만들 배음의 시작 주파수와 끝 주파수를 정의해준다
   2. 데시벨 EQ를 curfreq과 nextfreq 사이에 해당하는 부분만 슬라이싱해서 딱 가져와준다. 근데 여기서 중요한건, 이게 상승하면 문제가 없는데 하강하면 반전해서 가져와줘야 한다.
   3. 이걸 샘플 수에 맞게 보간해준다. 예를들어서 EQ 배열이 [1, 3, 5]였는데 만들고자 하는 오디오 샘플수가 5라면 [1, 2, 3, 4, 5]로 좌우로 길게 늘려주는거다. 저 사이에 평균계산돼서 값이 채워지는데 이걸 보간이라고 한다.
   4. 그 보간해서 만든 새로운 데시벨 EQ를 가지고 curfreq에서 nextfreq으로 변화하는 소리를 만든다
   5. 이 만든걸 output에다가 가산한다
   6. 1~5의 과정을 필요한 배음 수 만큼 각각에 대해 반복해준다
4. 만든 최종 소리를 반환한다
